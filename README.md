# nassauTickets

Sistema web para controle de atendimento em um Laboratório de Análises Clínicas.

## Objetivo

Desenvolver um sistema para organizar e controlar o atendimento de clientes em um laboratório de análises clínicas, utilizando um sistema de emissão e chamada de tickets (senhas).

## Tecnologias

-React
-Node.js
-Express
-MySQL
-Git e GitHub
